# Nabledge-1.2
## 機能

Nabledge-1.2は **知識** と **ワークフロー** の2種類の機能を提供します。

### 知識

Nablarch 1.2のドキュメントやベストプラクティスをエージェントが参照できるようにします。

Nablarch 1.2の全ドキュメントをカバーしています。

### ワークフロー

Nablarchの知識を活用した開発支援ワークフローを提供します。

現在提供しているワークフロー:

- **知識検索**: Nablarchの知識ファイルから質問に回答する
- **コード分析**: Nablarchの観点からプロジェクトコードを分析し、構造や依存関係を可視化したドキュメントを生成する
